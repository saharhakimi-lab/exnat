תרגול אינטראקטיבי להבנת פקודות Static, Dynamic ו-PAT (Overload) בנתבי Cisco

משימה 1 מתוך 10

איך מתרגלים?

בכל שלב תוצג משימת הגדרת NAT ברשת הארגונית. עליך ללחוץ על המילים ב"בנק המילים" (משמאל) לפי התחביר הנכון כדי לבנות את הפקודה המדויקת, ולאחר מכן ללחוץ על "הרץ פקודה".
שימו לב: אם תהיה טעות, המערכת תכוון אותך בשאלה סוקרטית כדי לעזור לך להבין את הלוגיקה של מבנה הנתונים.

Static: ip nat inside source static [local-ip] [global-ip] Dynamic: ip nat inside source list [acl] pool [pool-name] PAT (Overload): ip nat inside source list [acl] interface [int-name] overload
